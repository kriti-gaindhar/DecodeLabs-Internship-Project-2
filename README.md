# DecodeLabs-Internship-Project-2
# 📱 Responsive Web Layout

A modern, mobile-first responsive website built using **HTML5**, **Tailwind CSS**, and **JavaScript**. This project demonstrates responsive web design principles by adapting seamlessly to different screen sizes while maintaining an attractive and user-friendly interface.

---

## 🚀 Features

- 📱 Mobile-First Design
- 📐 Responsive Grid Layout
- 🎨 Tailwind CSS Styling
- 🍔 Hamburger Navigation Menu
- 📏 Fluid Typography & Layout
- 💻 Cross-Device Compatibility
- ⚡ Lightweight and Fast
- 🎯 Accessible Touch-Friendly Buttons

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6)
- CSS3

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/kriti-gaindhar/DecodeLabs-Internship-Project-2.git
```

2. Navigate to the project folder

```bash
cd DecodeLabs-Internship-Project-2
```

3. Open `index.html` in your preferred browser.

## 📖 Usage

- Resize the browser window to observe the responsive layout.
- Open the website on a mobile device to test the hamburger navigation.
- Explore how CSS Grid and Flexbox adapt content across different screen sizes.
